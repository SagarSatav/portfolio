# Portfolio knowledge (AI only)

Generated by `npm run knowledge:export` → `scripts/export-knowledge.mjs`.

## What that script does

**Only read + write sync:**

1. Reads `frontend/src/data/*.js`
2. Writes `profile.md`, `skills.md`, `projects.md`, `experience.md` here

It does **not** show on the UI, call APIs, or run AI ingest.

Do not edit these `.md` files by hand — change site data, then re-run:

```bash
cd ~/portfolio
npm run knowledge:export
```
